---
name: Portfolio parity
description: User expectation that the Replit portfolio and GitHub Pages portfolio stay consistent.
---

Apply portfolio content and design changes to both the Replit app and GitHub Pages static site.

**Why:** The user repeatedly requested that both platforms show the same content and design, and previously reported changes missing from Replit.

**How to apply:** Check both versions when modifying a portfolio section. Distinguish updates to GitHub Pages source files from changes actually published to the live GitHub Pages website.
