Keep an editable LaTeX manuscript in the project and direct the portfolio's book link to its compiled PDF.

**How to apply:** Preserve the LaTeX-to-PDF workflow and keep the public PDF consistent between the Replit app and GitHub Pages. Explain when compilation and publishing are required; never imply an unpublished workspace edit has already updated the live website.
